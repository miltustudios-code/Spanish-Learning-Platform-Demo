# Español A2 · Miltu Studios

General demonstration for language institutes, adapted from the UDLA demo without changing the original site.

## Theme and activities

Planes y tiempo libre. Two connected sequences, each containing reading, listening, writing and speaking (eight activities total):

- Organizamos una salida: an invitation, a voice message, a written confirmation and an oral invitation.
- Cambiamos el plan: two activity listings, a changed plan, a written alternative time and an oral alternative.

Reading/listening include three questions with explanations. Writing includes a 60–80 word model, word counter, self-check, a simple rule-based revision guide and local teacher review. Speaking supports temporary microphone recording, playback, a timer and self-assessment. Listening includes two bundled Spanish MP3 files with synthetic voices, slow/replay/stop controls, a native audio player and transcripts. Audio does not depend on the visitor having a Spanish speech voice installed.

## Classroom demo

Student and teacher views; fictional learners; assignment creation; teacher feedback; progress; an eight-minute reading/listening practice sample; a two-week study plan. All data stays in the browser's local storage. Teacher/student actions are connected on the same browser only. Microphone recordings are temporary and are not uploaded. There is no real login, backend, AI marking or official exam scoring.

## Publish on GitHub Pages

Upload index.html, styles.css, content.js, academic.js and app.js plus the assets folder to the root of a new repository. Enable Pages from the main branch, root folder. No build, dependencies, keys or server required. Keep the UDLA repository unchanged.

Student entry: / or /#inicio
All eight activities: /#cursos
Teacher summary: /#docente/resumen

B2/C1/C2 outline cards are proposals only; the functional content is A2. Branding, syllabus, courses and evaluation criteria can be adapted for each institute.
